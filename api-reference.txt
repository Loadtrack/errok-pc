# Справочник API errok.ru для «errok для ПК»

Все адреса ниже публичные: только чтение, без входа и ключей. База `https://errok.ru`. Ответы в JSON (UTF-8), хостинг их не сжимает. Даты везде в виде `ДД.ММ.ГГГГ`. Имена групп и ФИО в адресе кодировать (`encodeURIComponent` / `urlencoding`).

Проверено на живом сервере 01.11.2026.

## Общие правила

- Хостинг reg.ru закрывает IP примерно на 2 часа после всплеска запросов, без ответа (запросы висят до таймаута). Фоновый опрос: `available.json` не чаще раза в 3 минуты со случайным сдвигом, остальное по необходимости, без параллельных пачек.
- Статические файлы (`available.json`, файлы ОмАЭиП) отдают `ETag` и `Last-Modified`: спрашивать с `If-None-Match`, ответ 304 = без изменений.
- Заголовок `Authorization` хостинг срезает, но программе он и не нужен.
- `Access-Control-Allow-Origin` только для errok.ru: запросы делать из Rust, не из webview.
- Свой `User-Agent`: `errok-desktop/<версия> (Windows)`. Таймаут 20 секунд.
- Адреса, которых здесь нет (`api.php`, `api/tg.php`, `api/token.php`, `q/data.php`, `api/parser_bridge.php`, `api/site_overlay.php` и другие), программе не использовать: они внутренние.

## ОПЭК

### 1. Выложенные дни: `GET /available.json`

```json
{
  "30.10.2026": "3e2aa33b90fd2456",
  "31.10.2026": "50e159bf0520f546",
  "02.11.2026": "da0ba8143bcef54b",
  "highlighted": ["02.11.2026", "30.10.2026"],
  "archived": []
}
```

- Ключ: дата, значение: хеш файла дня (16 hex). Хеш меняется, когда день перевыкладывают с изменениями.
- Новый ключ = вышло расписание на новый день.
- `highlighted` и `archived` не даты, а служебные списки сайта (подсвеченные в календаре дни, архивные дни). При разборе их пропускать.
- Файл маленький (~5 КБ), с ETag. Это главный источник для уведомлений.

### 2. Дни по группам и преподавателям: `GET /api/fav_days.php`

Параметры:

| Параметр | Что | Ограничение |
|---|---|---|
| `from`, `to` | диапазон дат | не больше 16 дней |
| `g[]` | группа, можно несколько раз | до 8 |
| `t[]` | преподаватель, можно несколько раз; ищется вхождением в `teacher` без учёта регистра | до 8 |

Нужен хотя бы один `g[]` или `t[]`. Лимит сервера: 40 запросов в минуту с IP, при превышении 429 и заголовок `Retry-After`. Ошибки: `{"ok":false,"error":"bad_range" | "no_favorites" | "rate_limited" | "server"}`.

Пример: `/api/fav_days.php?from=02.11.2026&to=07.11.2026&g[]=БП2-113&t[]=Польченко А.О.`

Ответ (сокращён, данные настоящие):

```json
{
  "ok": true,
  "days": {
    "02.11.2026": {
      "date": "02.11.2026",
      "week": 2,
      "day": "Понедельник",
      "groups": [
        {
          "name": "БП2-113",
          "lessons": [
            {"pair": 3, "subgroups": [
              {"pg": 0, "discipline": "Физ-ра", "teacher": "Мальцева Т.А.", "room": "С.з 3к", "changed": false}
            ]},
            {"pair": 4, "subgroups": [
              {"pg": 0, "discipline": "Разраб.прог.модулей", "teacher": "Рудакова О.И.", "room": "547", "changed": false}
            ]}
          ]
        }
      ],
      "gym": {"3": {"с/з 3": ["БП2-113", "О-26"]}},
      "total": 75,
      "ov": {
        "overlay": {}, "announcements": {}, "hw": {}, "extra": {},
        "hidden": [], "diffs": [],
        "statuses": {"БП2-113": "учеб.пр.+теорет.обуч."},
        "bundle_ver": "2026.11.01-1326"
      }
    }
  }
}
```

Поля дня:

- `days` содержит все выложенные дни диапазона, даже если у выбранных пар нет (тогда `groups` пустой). Дня нет в `days` = расписание на него не выложено.
- `week`: 1 или 2 (недели чередуются). `day`: «Понедельник» … «Суббота».
- `groups`: выбранные группы и группы, у которых в этот день ведут пары выбранные преподаватели (группа целиком; пары преподавателя отбирать по `teacher` у подгрупп).
- `groups[].status`: статус группы, есть не всегда; полный список в `ov.statuses`.
- `lessons`: только пары, которые есть. `pair`: номер 1–6.
- `subgroups[]`: `pg` (0 = вся группа, 1/2 = подгруппы), `discipline`, `teacher`, `room`, `changed` (отличается от постоянного расписания).
- `gym`: кто ещё в ту же пару в том же спортзале или актовом зале, `{пара: {зал: [группы]}}`. На сайте это «Вместе с».
- `total`: сколько всего групп в дне.

Поле `ov` (правки и дополнения с сайта, применять поверх `groups`):

| Поле | Формат | Что делать |
|---|---|---|
| `overlay` | `{группа: {пара: {pg: {discipline?, teacher?, room?, by_role}}}}` | ручная правка пары: заменить указанные поля, показать «изменено» |
| `extra` | `{группа: {пара: {discipline, teacher, room, ts}}}` | доп. пара, поставленная вручную: добавить с пометкой «доп. пара» |
| `announcements` | `{группа: [{text, by_role, pair, ts}]}` | объявление; `pair` 0 = на весь день, иначе «на N пару» |
| `hw` | `{группа: {пара: {pg: {text, by_role, ts}}}}` | домашнее задание к паре |
| `hidden` | `[группа]` | группа на эту дату не учится: «Занятий нет» |
| `diffs` | `[{group, pair, kind}]`, `kind`: `added` / `removed` / `modified` / `status` | что поменял колледж за последние 24 часа; подсказка, сравнение всё равно делать самим |
| `statuses` | `{группа: статус}` | статус группы на дату |
| `bundle_ver` | строка | версия сайта, программе не нужна |

`by_role` (кто правил): `headman` от старосты, `deputy` от зам. старосты, `curator` от куратора, `teacher` от преподавателя, `admin` от errok.ru. `ts`: время в секундах Unix.

Правки, объявления, ДЗ и доп. пары не меняют `available.json`, поэтому сегодня и завтра надо перечитывать раз в 15 минут.

### 3. Справочник групп и преподавателей: `GET /api/fav_days.php?catalog=1`

```json
{"ok": true, "groups": ["ББ-125", "ББ-126", "БД-144", "…"], "teachers": ["Андреев М.А.", "Андреева Ю.С.", "…"]}
```

Около 75 групп и 107 преподавателей. На сервере кэш на час; программе хватит раза в сутки.

### 4. Постоянное расписание группы: `GET /api/perm_data/<группа>.json`

404, если для группы его нет.

```json
{
  "group": "БП2-113",
  "from": "2026-09-18", "to": "2026-12-31", "label": "18.09.2026",
  "weeks": {
    "1": {"Понедельник": {"3": [{"pg": 0, "d": "Поддерж.и тест.прогр.модулей", "t": "Гуркова Ю.Р.", "r": "БЕЗ АУД"}]}},
    "2": {"…": {}}
  }
}
```

Действует с `from` по `to`. Неделю выбирать по `week` выложенного дня (или по чередованию от него). `d` дисциплина, `t` преподаватель, `r` аудитория, `pg` подгруппа.

### 5. Экзамены и консультации: `GET /api/exams.php`

```json
{"updated": "2026-10-31", "year": "2026-2027", "items": [
  {"id": "b3a8c59773b", "group": "Э-43", "date": "13.10.2026", "kind": "consult", "time": "13:45",
   "room": "РЦ-3", "module": "ПМ.06", "title": "Малая автоматизация технологических процессов",
   "teachers": ["Михеева Е.В.", "Иванов Ю.Д."]}
]}
```

`kind`: `exam` экзамен, `consult` консультация. Поля `room`, `module`, `teachers` бывают не всегда. Кэш 60 секунд; программе хватит раза в час.

### 6. Прогноз пар: `GET /api/forecast_opec.json` (не для первой версии)

Пересчитывается ночью, неделя вперёд, ~380 КБ. Брать не чаще раза в 6 часов условным запросом. Показывать только на даты, которых нет в `available.json`, и явно как прогноз.

Пример формата (записи из разных групп собраны вместе и сокращены):

```json
{
  "generated": "2026-11-01T19:29:49", "model": "v3", "known_until": "2026-10-31", "horizon_days": 7,
  "names": {"БХТ2-35": [["Общ.и неорган.химия", "Юнусова А.А."], ["…", "…"]]},
  "days": {
    "03.11.2026": {
      "week": 2,
      "groups": {"БХТ2-35": [
        {"pair": 2, "pg": 2, "d": "Ин.яз.в ПД", "t": "Жердева Т.И.", "r": "б.а..",
         "held": 0.49, "exists": 0.647, "day": 0.544, "rp": "301", "rq": 0.75, "alt": [[1, 0.03]]},
        {"pair": 5, "pg": 0, "add": 1, "p": 0.46, "alt": [[0, 0.13]], "ar": "542", "arq": 0.88}
      ]},
      "statuses": {"ЭК1-204": "производ.практика"}
    },
    "04.11.2026": {"holiday": "День народного единства"}
  }
}
```

- Обычная запись: пара по постоянному расписанию. `held` вероятность, что она пройдёт; `exists` что в это время будет хоть какая-то пара; `1 - exists` что её снимут; `day` что дисциплина будет в этот день в любое время; `rp`/`rq` вероятная аудитория и её вероятность (если `rp` нет, вероятнее аудитория `r`).
- `alt`: возможные замены `[номер в names[группа], вероятность]`.
- Запись с `add: 1`: в постоянном пары нет, но её могут добавить с вероятностью `p`; `alt` что поставят, `ar`/`arq` аудитория первого варианта.
- `holiday`: праздник, пар нет. `holiday_maybe`: возможно выходной. `statuses`: группы на практике по графику (пар не будет).

### 7. Состояние сервисов: `GET /api/status.php`

```json
{"ok": true, "state": "ok", "summary": "Все системы работают", "diagnosis": "", "data_age": 75, "checked_at": 1793549004}
```

`state`: `ok`, `warn` или `down`. При `warn`/`down` показать `summary` (или `diagnosis`) в окне, например «расписание может обновляться с задержкой». Спрашивать только при открытом окне и не чаще раза в 10 минут.

### 8. Объявление сайта: `GET /notice.json`

```json
{"active": true, "level": "warn", "id": "tech-2026-04-25", "text": "Сайт на технических работах до 19:00",
 "until": "2026-04-25T19:00:00", "dismissable": true}
```

Показывать полосой в окне, если `active` и `until` ещё не прошёл. `level`: `info` / `warn` / `error` / `success`. В `text` бывают `\n` и ссылки `[текст](https://…)`. Закрытые пользователем `id` запоминать. Раз в 30 минут.

## ОмАЭиП

`fav_days.php` для ОмАЭиП не работает (справочник пустой). Данные лежат готовыми файлами:

| Адрес | Что |
|---|---|
| `GET /d/omaep/daily/available.json` | выложенные дни: `{"02.11.2026": "02.11.2026", …}` (без хешей) |
| `GET /d/omaep/daily/schedule_ДД.ММ.ГГГГ.json` | день целиком на весь колледж, ~120 КБ, ~90 групп, с ETag |
| `GET /d/omaep/weeks/available.json` | справочник групп: `{"222": {"name": "Б-9.35", "dates": ["…"]}, …}` |
| `GET /d/omaep/ics.php?group=<id>` | календарь группы в формате iCalendar (`<id>` из справочника), можно дать кнопку «Добавить в календарь» |

Формат дня тот же, что у ОПЭК (`date`, `week`, `day`, `groups[].lessons[].subgroups[]`), но без `ov` и с полем `type` у подгруппы: «Пр», «Лек», «Лаб», «Кураторский час», «Тек. аттест.» и др. Изменения дня определять условным запросом `schedule_<дата>.json` (304 = без изменений), только для сегодня, завтра и новых дат, не чаще раза в 5 минут.

## Значения в данных

- «ДИС» в аудитории: дистанционно (Moodle lect.ompec.ru). По субботам почти всегда.
- «без ауд.», «без аудит», «без.а.», «БЕЗ АУД», «б.а.», «б.а.3», «Б.А.1»: аудитория не назначена.
- «ФК» в дисциплине: дополнительные занятия, не физкультура.
- Сокращённые названия дисциплин («Разраб.прог.модулей») так и показывать; переносить строку после точки, а не посреди слова.
